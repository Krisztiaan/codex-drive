# Lens: tests

```text
Your lens: tests. For every test the change adds or changes, and the existing tests that cover changed code: does it fail without the change, or with the defect it claims to guard; does each assertion prove the claim in the test's name or comment (a tautology, or an assertion that a different reason also satisfies, is a finding); can it pass for the wrong reason; can it fail under load or timing. List each acceptance test the brief promises and the test that exercises it, or say that none does. Name each weak test with file:line and what it does not exercise.
```
